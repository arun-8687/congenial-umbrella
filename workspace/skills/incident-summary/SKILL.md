# Incident summary

Write these sections in order, each a few sentences at most:

- **Impact**: who was affected, how, and for how long (with UTC times).
- **Timeline**: detection, mitigation, resolution.
- **Root cause**: the technical cause, without naming individuals.
- **What went well / what didn't**
- **Follow-ups**: one line each, with an owner team and a linked issue if one exists.
